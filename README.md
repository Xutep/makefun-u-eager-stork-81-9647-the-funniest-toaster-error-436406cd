`main.py` (Python 3, standard library only, deterministic) writes one line —
the error message a kitchen toaster shows its owner — to `/output/entry.txt`:

> WARNING: THIS BREAD HAS BEEN TOASTED BEFORE. IT REMEMBERS.

Run it with `python3 main.py`. The gate requires 1–120 characters of UTF-8
text; this line is 58 characters.
